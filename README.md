# 📋 Paste App

A modern and responsive Paste Management Application built using **React.js**, **Redux Toolkit**, and **Vite**. This application allows users to create, manage, search, edit, copy, and delete text snippets with a clean and intuitive user interface.

---

## ✨ Features

- 📝 Create and save text pastes
- ✏️ Edit existing pastes
- 👀 View paste details
- 🗑️ Delete unwanted pastes
- 📋 Copy paste content with a single click
- 🔍 Search pastes by title
- ⚡ Fast performance powered by Vite
- 🎯 State management using Redux Toolkit
- 📱 Responsive and user-friendly design

---

## 🖼️ Application Preview

### 🏠 Home Page

The Home Page enables users to create and save new pastes by providing a title and content.

**Features:**
- Enter a paste title
- Write paste content
- Create and save notes instantly
- Clean writing interface

### 📂 Pastes Page

The Pastes Page displays all saved pastes and provides management options.

**Available Actions:**
- Search pastes
- View paste details
- Edit existing pastes
- Copy content to clipboard
- Delete pastes

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/paste-app.git
```

### Move Into Project Directory

```bash
cd paste-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Create Production Build

```bash
npm run build
```
